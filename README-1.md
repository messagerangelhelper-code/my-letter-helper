# My Letter Helper

Ready-to-send letters for everyday problems: credit card disputes, credit report errors,
debt collectors, refunds, cancellations, landlords and identity theft.

- Fill in the blanks; the letter builds itself as you type, with any empty blanks highlighted.
- Copy, email, share, or print / save as PDF (only the letter prints).
- Each letter says when to use it, any deadline, how to send it, tips, and official sources (CFPB, FTC).
- Your name and address are saved on the phone only. The app never asks for Social Security or full card numbers.

Free: every letter. Premium (through CashCow): My Letters, sent dates and follow-up reminders.
One CashCow account works here and in the other CashCow apps.

Letters live in `letters.js`. Rebrand in `brand.js`. Wording rule: general information, not legal advice.

## Render (Static Site)
- Build command: `npm install && npm run build`
- Publish directory: `dist`
